# MobileNetV3Small fashion classifier

This directory contains the active family-aware checkpoint (`best.keras`),
its training configuration, saved evaluation and source provenance.

Run identifier: `mobilenet_family_v1_77a4872e94084b1fbda881dab6316972`.

Inference verifies the checkpoint and configuration against fixed SHA-256
hashes. Original metadata records historical dataset paths and source identities;
the dataset paths are not needed for inference.

The executed-source snapshot `training_source.py` and completion record
`COMPLETE.json` referenced by the historical run are not included. The working
training source remains in `scripts/`; source provenance records its difference
from the executed snapshot. Complete research verification requires the matching
original inputs and run artifacts. Saved benchmark results do not measure
independent natural-photo accuracy.
